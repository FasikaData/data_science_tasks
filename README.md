# Data Science Tasks & Projects

Welcome to my Data Science repository! This project focuses on data preprocessing, feature encoding, and predictive modeling for socioeconomic datasets.

## 📌 Projects Included

### 1. Household Wealth Index Analysis & Machine Learning
- **Objective:** Preprocessing survey and household data to analyze wealth indices and build predictive machine learning models.
- **Tech Stack:** Python, Pandas, Scikit-learn, Jupyter Notebook, Stata (`.dta` data integration).
- **Key Steps:**
  - Data Cleaning & Preprocessing (handling missing values, categorical encoding).
  - Feature selection for wealth classification.
  - Model building and evaluation.

## 🛠️ Tools & Technologies Used
- **Languages:** Python, R, Stata
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook, VS Code
